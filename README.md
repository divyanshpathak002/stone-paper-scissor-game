# Stone Paper Scissors Game 🎮

A simple **Stone Paper Scissors game** made using **HTML, CSS, and JavaScript**.

## 🚀 Features

* Player can choose Stone, Paper, or Scissors.
* Computer makes a random choice.
* Displays the winner.
* Shows the game score.
* Simple and user-friendly design.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Choose **Stone, Paper, or Scissors**.
5. Enjoy the game! 🎮

## 🎯 Game Rules

* **Stone beats Scissors**
* **Scissors beats Paper**
* **Paper beats Stone**
* If both choose the same option, it is a **Draw**.
